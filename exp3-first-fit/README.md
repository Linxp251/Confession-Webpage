# 实验三：可变分区内存分配首次适应算法模拟

## 实验说明

本实验使用 C++ 实现可变分区内存管理的首次适应（First Fit）分配算法，通过双向链表管理内存分区，支持分配、回收与相邻空闲分区合并。

## 文件说明

| 文件 | 说明 |
|------|------|
| `first_fit.cpp` | 主程序源代码 |
| `in.txt` | 批处理测试输入（640KB 标准请求序列） |
| `Makefile` | 编译脚本 |
| `实验三_可变分区内存分配首次适应算法模拟.docx` | 完整实验报告（含代码与截图） |
| `screenshots/` | 运行截图目录 |

## 编译与运行

```bash
# 编译
make

# 批处理模式（推荐）
./first_fit batch in.txt

# 交互式模式
./first_fit
```

初始内存 640KB，请求序列：
